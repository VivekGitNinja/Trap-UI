# TRAP UI Frontend

Next.js 14 App Router frontend for TRAP UI SaaS.

## Stack
- Next.js 14
- TypeScript
- TailwindCSS
- ShadCN-style component structure
- Recharts

## Features
- Auth screens (Register/Login)
- Protected app shell
- URL analyzer form + job polling
- Dashboard:
  - Score meter
  - Score breakdown charts
  - CTA analysis
  - Color palette preview
  - Industry benchmark delta
- Reports listing

## Environment
```bash
NEXT_PUBLIC_BACKEND_URL=http://localhost:4000
```

## Run
```bash
npm install
npm run dev
```
